# Portfolio content verification checklist

## Profile
- [ ] Confirm preferred job title and Dubai relocation wording.
- [ ] Add GitHub username and public profile URL.
- [ ] Review contact email and phone visibility.
- [ ] Add approved resume PDF.

## Every project
- [ ] Verify problem, solution and user workflow.
- [ ] Verify exact personal contribution.
- [ ] Verify complete technology stack.
- [ ] Add architecture based on actual implementation.
- [ ] Add screenshots or a clearly labelled independent recreation.
- [ ] Add demo video or walkthrough.
- [ ] Add measurable results only when supported by evidence.
- [ ] Confirm ownership and publication permissions.

## Company projects
- [ ] Obtain permission for company name/logo if needed.
- [ ] Use sanitized diagrams.
- [ ] Do not publish private source code, credentials, internal endpoints or customer data.
- [ ] Clearly identify the work as company experience.

## Personal projects
- [ ] Rebuild clean public repositories from original work.
- [ ] Add README, setup steps, tests and sample environment file.
- [ ] Remove secrets and private data.
- [ ] Add license only after deciding appropriate ownership terms.
